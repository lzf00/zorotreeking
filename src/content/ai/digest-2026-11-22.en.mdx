# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2611.26232" target="_blank" rel="noopener noreferrer">Time Series Structure Learning with Local Causal Parent Discovery</a>

*HF ★ 2 · Jacqueline Maasch, Shu Wan, Hank Zhu… · [HF Mirror](https://huggingface.co/papers/2611.26232)*

To address the high algorithm complexity pain points of time series causal discovery caused by autocorrelation, distribution shift, and curse of dimensionality, this paper proposes ITPD (Iterative Temporal Parent Discovery): it adopts a local-to-global approach, leveraging temporal priors, graph partitioning and other methods to implement reduced-order conditional independence tests. Experiments show it requires the fewest test runs, takes far less time than baselines on large graphs with over 1000 nodes, and is up to 40.9x faster than benchmarks for 2000-node graphs, achieving Pareto optimality in both F1 score and time consumption.

## <a href="https://arxiv.org/abs/2611.26239" target="_blank" rel="noopener noreferrer">Teaching Vision-Language-Action Models to Stop Safely</a>

*HF ★ 5 · Zheyuan Liu, Chuhan Wang, Jinduo Guo… · [HF Mirror](https://huggingface.co/papers/2611.26239)*

To solve the problem that existing vision-language-action (VLA) robot models cannot safely stop prohibited tasks mid-execution, leading to safety risks such as falling objects, this paper proposes SAFI, a two-stage state-aware fallback imitation method that sets safe stop responses for prohibited tasks while retaining the model's original task capabilities. Experiments show this method reduces the completion rate of prohibited tasks after mid-execution intervention to 1.3%, with zero safety incidents, and the original task performance remains fully intact.

## <a href="https://arxiv.org/abs/2611.25604" target="_blank" rel="noopener noreferrer">PAD: Policy-Aware Data Valuation for Autonomous Driving</a>

*HF ★ 4 · Chengkai Xu, Yicheng Guo, Jiaqi Liu… · [HF Mirror](https://huggingface.co/papers/2611.25604)*

To address the issues that data scaling for end-to-end autonomous driving does not deliver proportional gains and existing data filtering does not match the utility of downstream policies, this paper proposes PAD, a policy-aware data valuation framework that combines scene calibration feedback, policy gradients, and geometric regularization approximation of local training to generate customized data utility scores for target driving policies. This method adapts to multiple planner architectures, improves the EPDMS metric by up to 5.0 compared to full dataset/pure real-vehicle training, reduces scene degradation, and greatly improves training efficiency.

## <a href="https://arxiv.org/abs/2611.15941" target="_blank" rel="noopener noreferrer">Lang-SVG: Hierarchical Image Vectorization with Language Priors</a>

*HF ★ 1 · Xi Liu, Chaoyi Zhou, Run Wang… · [HF Mirror](https://huggingface.co/papers/2611.15941)*

To solve the problem that existing image vectorization methods only pursue pixel restoration accuracy, resulting in SVGs that do not conform to human-perceived component hierarchies and have poor editability, this paper proposes Lang-SVG: it organizes SVG primitives with semantic trees, integrates open-vocabulary segmentation priors and semantics annotated by multimodal LLMs, and is paired with optimizations including adaptive simplification, tree-guided pruning and merging, and SAM prompt completion. Under the self-developed evaluation system that balances structure and semantic alignment, it achieves SOTA in both rendering accuracy and structural quality.

## <a href="https://arxiv.org/abs/2611.25200" target="_blank" rel="noopener noreferrer">Squoosh Bench: Evaluating UX-1 on 318 Historical Website A/B Tests</a>

*HF ★ 3 · Rohith Pasula, Johari Dramiga, Viraj Shah… · [HF Mirror](https://huggingface.co/papers/2611.25200)*

This study evaluates the pre-selection effect of simulated browsing prediction models for test solutions based on 318 historical web A/B test datasets with durations of over 21 days. The Squoosh UX-1 model fine-tuned on human browsing data reaches 84% prediction accuracy, far outperforming the 61.6% of general LLM Qwen3 Next 80B; the test variants it predicts to win have a real-world win rate of 93.7% after launch, effectively supporting pre-selection of A/B test plans.

# Lil'Log

## <a href="https://lilianweng.github.io/posts/2026-07-04-harness/" target="_blank" rel="noopener noreferrer">Harness Engineering for Self-Improvement</a>

*Lilian Weng*

Recursive Self-Improvement (RSI) was first proposed by I.J. Good in 1965, referring to the operating logic of superintelligence that can surpass all human intellectual activities and independently design better systems to achieve iteration. In 2008, Eliezer Yudkowsky clarified its core as the feedback loop where AI uses existing intelligence to optimize its own cognitive architecture. Currently, RSI implementation in the AI field is divided into two categories: one is models directly rewriting their own weights, the other is models optimizing training pipelines.

## <a href="https://www.qbitai.com/2026/11/511841.html" target="_blank" rel="noopener noreferrer">80,000 group chat messages made into test papers: Tencent Yuanbao × KCL releases first Agent memory benchmark built on group chats</a>

*QbitAI*

Tencent Yuanbao, in collaboration with King's College London, has released GroupAssistBench, the first Agent memory benchmark built on group chat scenarios. It constructs 2395 evaluation questions based on more than 80,000 messages from 50 real groups, and tests at two levels: memory recall and open service. After testing 14 technical configurations, the team found that strong Agent memory recall capability does not equal good actual service performance. The relevant datasets and code are now open source.
