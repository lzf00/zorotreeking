# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2610.33106" target="_blank" rel="noopener noreferrer">VibeGame: Prompt-to-Game Development with AI-Native Engine and Self-Evolving Adversarial Agent Team</a>

*HF ★ 11 · Wenbo Hu, Ken Li, Jiazhe Wei… · [HF Mirror](https://huggingface.co/papers/2610.33106)*

To address the pain point that LLM agents struggle to achieve end-to-end game development, this paper proposes the VibeGame framework, which can generate complete 2D game projects from natural language prompts (reference images can be optionally provided). It is equipped with an AI-native engine that converts project states into verifiable structured text, designs an adversarial team composed of 8 professional agents to separate development and review, and also supports training-free self-evolution to accumulate reusable components. In game generation benchmark tests, the framework significantly outperforms all similar solutions based on the same base model, including GPT-6.1-Sol.

## <a href="https://arxiv.org/abs/2610.38352" target="_blank" rel="noopener noreferrer">WeVisCut: The Whole Editing Room in One Agent From Narration to Long-Form Video</a>

*HF ★ 9 · Chenyu Mu, Wenming Weng, Qinrui Wang… · [HF Mirror](https://huggingface.co/papers/2610.38352)*

To solve the problems that narration-driven long-form video editing requires coherent cross-shot decision-making, and existing general multi-stage intelligent editing solutions fail to strike a good balance between quality and efficiency, this research proposes WeVisCut, an end-to-end script-to-long-video system. It links tool execution and policy learning through shared production status, and is paired with a four-stage data pipeline that generates 130,000 training samples to train a unified 9B-parameter policy. Actual tests show its performance far exceeds the baseline, is comparable to Claude Opus 5 but consumes 33 times fewer tokens per minute of output, and also outperforms native editing tools for the same task.

## <a href="https://arxiv.org/abs/2610.38425" target="_blank" rel="noopener noreferrer">IntReal: A Real-World Dataset and Benchmark for Multimodal Interleaved Generation</a>

*HF ★ 8 · Shaohan Yu, Jie Qin, Wende Tan… · [HF Mirror](https://huggingface.co/papers/2610.38425)*

To address the pain point that the multimodal interleaved generation field lacks standard tasks, training data and fine-grained evaluation solutions, this paper launches the IntReal suite: it includes a dataset of 100,000 real-world interleaved samples covering four major categories, as well as a 7-dimensional fine-grained evaluation system. The evaluation is highly reliable and well aligned with human judgments, can distinguish the performance of different unified multimodal models, and also finds that unimodal training can also improve interleaved generation effects, eliminating the need for full-stage joint image-text training.

## <a href="https://arxiv.org/abs/2610.37786" target="_blank" rel="noopener noreferrer">WebAnything: From the Wild Web to Scalable Agent Environments</a>

*HF ★ 8 · Tianci Xie, Zikun Cai, Chaoyun Zhang… · [HF Mirror](https://huggingface.co/papers/2610.37786)*

To address the pain point that existing environments for Web agent training and evaluation require manual adaptation site by site and have insufficient fidelity, this paper proposes the fully automatic framework WebAnything: it can reconstruct environments based on real URLs without manual adjustment per site, captures web page structure and interaction logic through an exploration and collection module, and is paired with a verification module for automatic repair and supplementary collection. The fidelity of the 244 cross-domain site environments it builds is better than manual solutions, and fine-tuning models with the trajectories it generates can improve task success rate by up to 13.33 percentage points.

## <a href="https://arxiv.org/abs/2610.37161" target="_blank" rel="noopener noreferrer">WorkFactory: Turning Professional Intents into Executable Work for Scalable Agent Training</a>

*HF ★ 6 · Ziyang Zeng, Tingyang Chen, Jia Deng… · [HF Mirror](https://huggingface.co/papers/2610.37161)*

To solve the problems of missing task information and poor consistency in supervised training of agents for professional tasks, this paper proposes the WorkFactory framework: it first builds an information support graph based on professional intent to generate tasks, then executes probe runs to fix defects and ensure executability. More than 110,000 tasks covering 612 occupations are built based on this framework, and the fine-tuned WorkPilot series models outperform base models of the same size across all professional benchmarks, verifying the effectiveness of the framework.

## <a href="https://lilianweng.github.io/posts/2026-07-04-harness/" target="_blank" rel="noopener noreferrer">Harness Engineering for Self-Improvement</a>

*Lilian Weng*

This article sorts out the theoretical context of Recursive Self-Improvement (RSI): In 1965, I.J. Good first proposed the relevant concept, defining a system that can surpass all human intellectual activities and design better machines to achieve self-iteration as an ultra-intelligent machine; In 2008, Eliezer Yudkowsky clarified that the core of RSI is the feedback loop where AI relies on existing intelligence to iteratively optimize its own cognitive modules. Currently, RSI implementation in the AI field can be divided into two categories: directly rewriting its own weights, and optimizing its own training pipeline.
