# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2610.34283" target="_blank" rel="noopener noreferrer">ChronoReplay: One Answer Interface Is Not Enough for Streaming Spatial Intelligence</a>

*HF ★ 72 · Yihao Hu, Yitong Lin, Pan Wang… · [HF 镜像](https://huggingface.co/papers/2610.34283)*

本文针对空间视觉大模型训练的「接口锁定」问题（单任务优化会损害其他空间任务迁移能力），提出ChronoReplay方法：将异构空间监督按时序重放，保留原生目标、平衡任务族监督。该方法在三个空间基准上均获提升，OST-Bench涨13.41点，为对比组三基准均值最高，推理端自适应选帧还可进一步降本提效。

## <a href="https://arxiv.org/abs/2610.36729" target="_blank" rel="noopener noreferrer">Hy-Nomas: Towards Free-form Interactive World Generation</a>

*HF ★ 41 · Qiaoling Chen, Jiaxiang Cheng, Xueqing Deng… · [HF 镜像](https://huggingface.co/papers/2610.36729)*

针对交互式世界生成需遵循指令、保留历史因果的需求，本文提出搭载8B参数扩散骨干的视频世界模型Hy-Nomas，支持多轮自由文本指令与连续相机控制。核心采用动作感知因果注意力、多模态提示增强器设计，搭配多阶段课程训练与扩散蒸馏，人工评估性能优于现有同类模型，已开源相关资源支撑领域研究。

<FeedbackButtons slug="item:arxiv-2610.36729" client:visible />

## <a href="https://arxiv.org/abs/2610.36068" target="_blank" rel="noopener noreferrer">Rollback: Experience Backtracking in World Models for Policy Improvement</a>

*HF ★ 41 · Jiayi Luo, Yang Zhang, Liliang Chen… · [HF 镜像](https://huggingface.co/papers/2610.36068)*

针对现有基于世界模型的机器人策略优化仅用前向仿真、未挖掘反事实推演能力的缺陷，本文提出Rollback范式：回溯关键决策点，对比不同动作收益生成细粒度动作监督，无需额外价值模型；还构建实机执行与世界模型训练的闭环，用实机数据经LoRA微调修正动力学。实验显示三个实机任务成功率较基线高10%以上，部分任务8小时训练超人类平均水平。

<FeedbackButtons slug="item:arxiv-2610.36068" client:visible />

## <a href="https://arxiv.org/abs/2610.37666" target="_blank" rel="noopener noreferrer">ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning</a>

*HF ★ 36 · Chaehyun Kim, Chi-Pin Huang, Jisoo Kim… · [HF 镜像](https://huggingface.co/papers/2610.37666)*

针对现有视觉-语言-动作（VLA）模型泛化受标注机器人演示限制、无标注人类视频学习难兼顾数据规模与动作接地的问题，本文提出ThinkWorld框架：以动力学链为通用动作表征，先靠标注演示初始化，再通过世界想象强化学习优化，可利用无标注视频状态跃迁做监督。实验验证其人-机迁移效果好，未知任务、环境泛化性强。

<FeedbackButtons slug="item:arxiv-2610.37666" client:visible />

## <a href="https://arxiv.org/abs/2610.36456" target="_blank" rel="noopener noreferrer">LociArt: A Unified Paradigm for Free-Style Local Video Stylization</a>

*HF ★ 25 · Yuxuan Chen, Feng Xie, Jiagao Hu… · [HF 镜像](https://huggingface.co/papers/2610.36456)*

针对现有视频风格化多适配全场景、局部编辑难兼顾区域精准性、风格可控性与时序一致性的痛点，本文提出局部自由风格化统一范式LociArt，核心GRNStyle模块采用风格感知极坐标掩码结合表征-几何约束方案，配套构建10万样本数据集与评测基准。实验显示其效果优于现有方法，单区域训练即可支持多区域同/异风格编辑。

## <a href="https://arxiv.org/abs/2610.33024" target="_blank" rel="noopener noreferrer">Evolving to Match Capabilities: Improving Harness Self-Evolution via Skill Adaptation</a>

*Zhihao Yang, Haojin Wang, Juncheng Wu…*

针对大模型代理Harness自进化中技能适配性差的问题——强模型适用的技能反而会拉低弱模型性能，本文提出技能适配方案：构建元技能诊断工具调用、上下文管理等四类执行失败，指导技能改写与自进化适配模型能力。实验显示弱模型性能最高提升14.1分，全能力段模型自进化后较基线高2.0-5.1分，为相关设计提供实用指导。

## <a href="https://arxiv.org/abs/2610.33025" target="_blank" rel="noopener noreferrer">Can Language Models Learn While They Think? Testing Gradient Adaptation Across Architectures</a>

*Surya Saka*

本文测试不同架构大模型推理时梯度动态适配效果：对软注意力、扩散模型按128token块做单步SGD更新，可降低5%-20%的下一词损失，效果优于32k长上下文窗口，混合线性注意力模型无明显增益。这类梯度适配仅捕获风格词汇不记忆事实，改用结论蒸馏到低秩适配器的方案可达上下文学习上限且不影响推理能力。

## <a href="https://arxiv.org/abs/2610.33029" target="_blank" rel="noopener noreferrer">Lessons from Luck: Do LLM-Written Lessons Carry Chance into an Agent's Next Decision?</a>

*Kazuki Nakayashiki*

该研究验证大模型生成的经验是否会将偶然结果带入智能体后续决策：在256个双工具合成任务场景下，对11个大模型端点开展共9万次受控测试。结果显示，好工具偶然失败的经验会让后续选次优工具的概率升至11.6%，未明确说明失败独立性的场景偏差更显著，优化经验写入指令可降低偏差但未完全消除风险。
