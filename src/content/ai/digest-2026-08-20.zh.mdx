## <a href="https://arxiv.org/abs/2608.18580" target="_blank" rel="noopener noreferrer">FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis</a>

*HF ★ 0 · Kou Shi, Zun Wang, Qisheng Su… · [HF 镜像](https://huggingface.co/papers/2608.18580)*

针对现有终端任务合成易出现组件不一致、丢失源意图导致任务无效的问题，本文提出FACET框架：先重构智能体技能为连贯场景，修复执行环境，以容器状态为指令、参考方案、验证器的统一锚点，仅针对性修复失效组件无需全量重生成。实验显示其生成的任务可提供高效监督，微调模型在Terminal-Bench2.1性能显著提升，验证了源意图保留、共享可执行状态锚定的核心价值。

## <a href="https://arxiv.org/abs/2608.17393" target="_blank" rel="noopener noreferrer">LEGO-RL: Harness-Native Reinforcement Learning for Coding Agents</a>

*HF ★ 2 · Yiming Du, Yuxin Jiang, Tao Yuan… · [HF 镜像](https://huggingface.co/papers/2608.17393)*

## <a href="https://arxiv.org/abs/2608.12944" target="_blank" rel="noopener noreferrer">CardioState-JEPA: Delay-Aware Cross-Modal Learning of a Shared Cardiac Representation</a>

*HF ★ 1 · Hamza Shafiq, Hung Manh Pham, Bin Zhu… · [HF 镜像](https://huggingface.co/papers/2608.12944)*

现有心脏基础模型多为单模态训练，未利用心电、脉搏、心音信号的生理关联。对此提出CardioState-JEPA基础模型，采用生理感知联合嵌入架构，新增时延对齐模块适配多模态时序偏移，可先基于海量单模态数据学习、再用少量配对数据对齐模态。其在25项下游任务中性能显著优于现有自监督基线，部分任务媲美有监督模型，验证了异质心脏信号联合监督的可行性。
