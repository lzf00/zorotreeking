# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2610.33106" target="_blank" rel="noopener noreferrer">VibeGame: Prompt-to-Game Development with AI-Native Engine and Self-Evolving Adversarial Agent Team</a>

*HF ★ 11 · Wenbo Hu, Ken Li, Jiazhe Wei… · [HF 镜像](https://huggingface.co/papers/2610.33106)*

针对大模型代理难以实现端到端游戏开发的痛点，本文提出VibeGame框架，可凭自然语言提示（可选配参考图）生成完整2D游戏项目。其搭载AI原生引擎将项目状态转为可校验结构化文本，设计8个专业代理组成的对抗团队分离开发与评审，还支持免训练自进化沉淀可复用组件。在游戏生成基准测试中，该框架表现显著优于同基底的各类同类方案，包括GPT-6.1-Sol。

## <a href="https://arxiv.org/abs/2610.38352" target="_blank" rel="noopener noreferrer">WeVisCut: The Whole Editing Room in One Agent From Narration to Long-Form Video</a>

*HF ★ 9 · Chenyu Mu, Wenming Weng, Qinrui Wang… · [HF 镜像](https://huggingface.co/papers/2610.38352)*

针对旁白驱动长视频剪辑跨镜头决策需连贯、现有通用多阶段智能剪辑方案质效平衡不足的问题，研究提出WeVisCut端到端脚本转长视频系统，通过共享制作状态联动工具执行与策略学习，配套四阶段数据 pipeline 生成13万训练样例训得9B参数统一策略。实测其性能远超基线，与Claude Opus 5效果相当但单分钟输出token消耗低33倍，也优于同任务原生剪辑工具。

## <a href="https://arxiv.org/abs/2610.38425" target="_blank" rel="noopener noreferrer">IntReal: A Real-World Dataset and Benchmark for Multimodal Interleaved Generation</a>

*HF ★ 8 · Shaohan Yu, Jie Qin, Wende Tan… · [HF 镜像](https://huggingface.co/papers/2610.38425)*

针对多模态交错生成领域缺乏标准任务、训练数据及细粒度评测方案的痛点，本文推出IntReal套件：含覆盖四大类的10万条真实世界交错样本数据集，及7维度细粒度评测体系。该评测可靠性强、与人类判断对齐度高，可区分不同统一多模态模型优劣，还发现单模态训练也能提升交错生成效果，无需全阶段执行图文联合训练。

<FeedbackButtons slug="item:arxiv-2610.38425" client:visible />

## <a href="https://arxiv.org/abs/2610.37786" target="_blank" rel="noopener noreferrer">WebAnything: From the Wild Web to Scalable Agent Environments</a>

*HF ★ 8 · Tianci Xie, Zikun Cai, Chaoyun Zhang… · [HF 镜像](https://huggingface.co/papers/2610.37786)*

针对Web智能体训练评估的现有环境需人工逐站适配、保真度不足的痛点，本文提出全自动框架WebAnything：可基于真实URL重建环境，无需逐站人工调整，通过探索采集模块抓取网页结构与交互逻辑，配套验证模块自动修复补采。其构建的244个跨领域站点环境保真度优于人工方案，用其生成的轨迹微调模型，任务成功率最高提升13.33个百分点。

## <a href="https://arxiv.org/abs/2610.37161" target="_blank" rel="noopener noreferrer">WorkFactory: Turning Professional Intents into Executable Work for Scalable Agent Training</a>

*HF ★ 6 · Ziyang Zeng, Tingyang Chen, Jia Deng… · [HF 镜像](https://huggingface.co/papers/2610.37161)*

针对智能体专业任务监督训练存在的任务信息缺失、一致性差问题，本文提出WorkFactory框架：先基于专业意图构建信息支持图生成任务，再通过探针执行修复缺陷保障可执行性。基于该框架构建覆盖612个职业的11万余项任务，微调得到的WorkPilot系列模型在专业基准上全面优于同规模基座，验证了框架有效性。
