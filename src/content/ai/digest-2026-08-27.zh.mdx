## <a href="https://arxiv.org/abs/2608.24979" target="_blank" rel="noopener noreferrer">FrontierChallenge: Evaluating Scientific Workflow Completion</a>

*HF ★ 94 · Liangcai Su, Zhaopeng Feng, Zhuo Chen… · [HF 镜像](https://huggingface.co/papers/2608.24979)*

针对现有科研智能体基准多侧重单领域、孤立任务的局限，研究团队推出跨领域端到端科研工作流评测基准FrontierChallenge，当前已发布覆盖6个科研领域的97项评测任务。对12个前沿模型搭配3种智能体架构的测试显示，最优通过率仅20.6%，高过程分、模型自报完成都不能代表任务真达标，凸显全流程交付完整性评测的必要性。

## <a href="https://arxiv.org/abs/2608.26005" target="_blank" rel="noopener noreferrer">VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction</a>

*HF ★ 68 · Zhifei Xie, Jiaqi Lang, Ze An… · [HF 镜像](https://huggingface.co/papers/2608.26005)*

针对对话系统缺乏适配实时交互的高性能流式记忆系统的问题，本文提出双脑结构记忆架构VoiceMem，分信息处理左脑、情感人设处理右脑，配套流式IO机制及完整训练、评测、可插拔部署管线。实验显示其检索准确率较Mem0高近30点，情感人设表现SOTA提升4.29分，检索仅134ms无额外延迟，可支撑实时个性化情感语音交互。

<FeedbackButtons slug="item:arxiv-2608.26005" client:visible />

## <a href="https://arxiv.org/abs/2608.24479" target="_blank" rel="noopener noreferrer">WarpSAC: Towards the Pinnacle of Scalable Off-policy RL by Rethinking Exploration and Exploitation</a>

*HF ★ 68 · Zihao Wu, Hongyao Tang, Yi Ma… · [HF 镜像](https://huggingface.co/papers/2608.24479)*

本研究发现离策略强化学习现有稳定器的效果随数据规模变化，据此提出场景感知的WarpSAC算法族：CPU数据有限场景启用参数归一化、双Q裁剪，GPU数据充足场景关闭归一化、改用单Q，搭配样本权重衰减提效。相比基准FlashSAC，其多场景得分、操作成功率、真机迁移速度均大幅提升，验证了稳定器适配数据场景的必要性。

## <a href="https://arxiv.org/abs/2608.19583" target="_blank" rel="noopener noreferrer">VGI-BENCH: Probing Visual Intelligence in Video Generation Models</a>

*HF ★ 46 · Xuan He, Cong Wei, Yuhao Cheng… · [HF 镜像](https://huggingface.co/papers/2608.19583)*

针对现有视频生成模型的零样本视觉推理能力缺乏适配性强、难度合理的可靠评测的问题，该研究推出VGI-Bench基准，包含27项任务共810个实例，采用任务域、技能标签双层分类实现细粒度评测。实测显示当前模型表现欠佳，最强模型Seedance 2.0准确率仅51%，推理纠错能力薄弱，基准将开源以推动领域研发。

## <a href="https://arxiv.org/abs/2608.25593" target="_blank" rel="noopener noreferrer">JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution</a>

*HF ★ 36 · Guibin Zhang, Leo Lu, Fangzhou Xie… · [HF 镜像](https://huggingface.co/papers/2608.25593)*

针对代理编排框架此前依赖人工设计、任务适配性差、难规模化的痛点，本文提出JIT-Agent：首个专门训练的即时编排智能模型，可按需生成适配任务的可组合框架，支持运行修复、经验蒸馏自进化。测试显示，接入该框架的DeepSeek、GLM等多款大模型性能最高提20.2分，比肩成熟商用编排方案，证实编排智能是独立于模型缩放的代理能力新维度。

## <a href="https://arxiv.org/abs/2608.24904" target="_blank" rel="noopener noreferrer">Dynamic Influence-Weighted Distillation for Single-IMU Activity Recognition</a>

*Bingxuan Xie*

针对单右臂IMU人体活动识别精度不足的问题，本文提出动态影响加权知识蒸馏方法：训练时用多IMU教师模型的logit、特征作为监督信号，通过训练内部分集验证单步更新效果，为每个样本的两类损失动态分配权重。在WEAR数据集上，该方法相较监督基线、固定权重蒸馏分别提升7.66、6.68个百分点的宏F1，部署无需改动原有传感方案和学生模型结构。

## <a href="https://arxiv.org/abs/2608.24936" target="_blank" rel="noopener noreferrer">GreenLeaf Law Embed Tiny: A Compact Embedding Model for Legal Domain Retrieval</a>

*Surya Saka*

本文推出0.6B参数量的轻量法律领域检索嵌入模型GreenLeaf Law Embed Tiny。采用两阶段训练：先从大模型蒸馏知识，再结合340万含15万人工标注的多司法辖区法律数据开展带硬负挖掘的领域微调，支持多精度量化推理。在两项法律检索基准上分别达75.11%、64.38%，为1B参以下模型中的领先水平，适配资源受限部署场景。
