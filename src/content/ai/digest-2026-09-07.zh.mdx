# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2609.04304" target="_blank" rel="noopener noreferrer">Iris: Climbing to the Search Frontier</a>

*HF ★ 8 · Ziyuan Liu, Hengqi Liu, Zichuan Wang… · [HF 镜像](https://huggingface.co/papers/2609.04304)*

本文推出两款不同参数规模的搜索代理Iris-mini、Iris-pro，基于网页链接反构无字符串匹配线索的多跳难搜数据集，采用SFT-RL交替迭代训练范式，严格控制变量开展评估。两款模型在四项搜索基准上均取得同参数级开源搜索代理最优成绩，后续将开源权重及全流程实现方案。

## <a href="https://arxiv.org/abs/2609.04523" target="_blank" rel="noopener noreferrer">MaxKernel: Agentic Kernel Generation for TPUs</a>

*HF ★ 3 · Shangkun Wang, Nina Cai, Charles Hoong… · [HF 镜像](https://huggingface.co/papers/2609.04523)*

针对TPU高性能定制内核开发需深厚硬件专业知识、门槛高的痛点，研究提出多代理内核生成系统MaxKernel，支持人在环协同设计、全自动指标驱动优化、基于图的全局设计空间探索三种模式，共享子代理完成开发全流程工作。经JaxBench基准及真实模型负载测试，生成内核性能对标专家手动调优结果，现已开源。

<FeedbackButtons slug="item:arxiv-2609.04523" client:visible />

## <a href="https://arxiv.org/abs/2609.05258" target="_blank" rel="noopener noreferrer">Ask Before You Optimize: Dynamic Pre-Formulation Clarification for Interactive Optimization</a>

*HF ★ 2 · Sihan Ge, Yichen Lin, Chenyu Zhou… · [HF 镜像](https://huggingface.co/papers/2609.05258)*

针对大模型从自然语言生成运筹优化模型时，常因用户需求不全导致建模偏差的问题，该研究推出OR-Clarify基准，可量化评估智能体建模前的澄清能力；还提出双阶段框架InterOPT，能识别关键信息缺口，自主判断该提问还是终止交互。实验显示其选择式场景性能远超基线，开放式场景也比肩现有先进方案。

<FeedbackButtons slug="item:arxiv-2609.05258" client:visible />

## <a href="https://arxiv.org/abs/2609.05416" target="_blank" rel="noopener noreferrer">WorldSculpt: Generating Compositional Worlds from Grounded Videos</a>

*HF ★ 2 · Muyao Niu, Jixuan He, Ruihan Yu… · [HF 镜像](https://huggingface.co/papers/2609.05416)*

针对高遮挡密集杂乱场景的3D组合生成难题，本文提出WorldSculpt方法：基于单物体3D生成模型Pixal3D拓展多视角条件通路，仅需单物体微调即可泛化到复杂场景，无需场景级训练。同时构建带精准标注的密集场景基准UE-MeshyScene，实验显示该方法效果优于现有方案，场景越复杂优势越显著，还可将3DGS场景转换为组合网格场景适配AR/VR等需求。

<FeedbackButtons slug="item:arxiv-2609.05416" client:visible />

## <a href="https://arxiv.org/abs/2609.04061" target="_blank" rel="noopener noreferrer">When Models Edit Too Much: On the Fidelity of Minimal Code Edits</a>

*HF ★ 2 · Tongyao Zhu, Wei Hern Lim, Min-Yen Kan · [HF 镜像](https://huggingface.co/papers/2609.04061)*

本研究针对大模型代码修复时的过度修改问题，构建含400个已知最小补丁的评测集测试，发现即便GPT-5.5这类强模型也常输出冗余修改。添加保留原实现的指令可显著降低过度编辑程度、小幅提升修复通过率，强化学习比监督微调更适配跨场景忠实编辑需求，应将编辑忠实度作为代码修复的独立质量维度。
