# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2611.26232" target="_blank" rel="noopener noreferrer">Time Series Structure Learning with Local Causal Parent Discovery</a>

*HF ★ 2 · Jacqueline Maasch, Shu Wan, Hank Zhu… · [HF 镜像](https://huggingface.co/papers/2611.26232)*

针对时序因果发现面临的观测自相关、分布漂移、维数灾难，以及通用算法计算与样本复杂度高的痛点，该研究提出迭代时序父节点发现算法ITPD，采用局部到全局思路，借助时序先验、图分区等降阶条件独立性检验。实验显示其检验次数更少、精度与耗时处于帕累托最优，千级节点场景下速度远超基线，2000节点时最高快40.9倍。

## <a href="https://arxiv.org/abs/2611.26239" target="_blank" rel="noopener noreferrer">Teaching Vision-Language-Action Models to Stop Safely</a>

*HF ★ 9 · Zheyuan Liu, Chuhan Wang, Jinduo Guo… · [HF 镜像](https://huggingface.co/papers/2611.26239)*

针对现有视觉-语言-动作（VLA）机器人模型无法安全中止执行中违禁任务、易出现坠物等安全隐患的问题，本文提出状态感知回退模仿方法SAFI：为违禁任务设定固定机械臂指令与稳定夹爪目标，联合适配策略兼顾原有任务能力。实测显示该方法将接管后违禁任务成功率降至1.3%，无物理事故，且保留原有任务高性能表现。

## <a href="https://arxiv.org/abs/2611.25604" target="_blank" rel="noopener noreferrer">PAD: Policy-Aware Data Valuation for Autonomous Driving</a>

*HF ★ 4 · Chengkai Xu, Yicheng Guo, Jiaqi Liu… · [HF 镜像](https://huggingface.co/papers/2611.25604)*

针对端到端自动驾驶现有数据筛选方法未关联下游策略效用的痛点，该文提出策略感知数据估值框架PAD，结合场景校准反馈、策略梯度与局部训练几何正则近似，为目标驾驶策略计算专属数据效用。实验显示PAD适配多类规划器，较基准训练指标提升3.5-5个点，可降低场景退化，替代无差别数据积累，提升训练效率。

## <a href="https://arxiv.org/abs/2611.15941" target="_blank" rel="noopener noreferrer">Lang-SVG: Hierarchical Image Vectorization with Language Priors</a>

*HF ★ 1 · Xi Liu, Chaoyi Zhou, Run Wang… · [HF 镜像](https://huggingface.co/papers/2611.15941)*

针对现有图像矢量化方法仅追求像素级还原，生成的SVG不符合人感知的部件层级、难以编辑的问题，本文提出Lang-SVG：以带语义标签的树结构组织SVG图元，融合开放词汇分割先验、多模态大模型标注、剪枝优化等技术，配套新的结构质量评测协议，实验显示其在渲染精度和结构质量上均达当前最优水平。
