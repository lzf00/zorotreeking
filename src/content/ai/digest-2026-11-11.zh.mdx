# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2611.12426" target="_blank" rel="noopener noreferrer">dNaViT: Discrete Codes are General-Purpose Visual Representations</a>

*HF ★ 19 · Xiaotong Li, Zhengrong Yue, Xu Huang… · [HF 镜像](https://huggingface.co/papers/2611.12426)*

为探索离散词表对视觉信息的表征上限、适配多模态统一建模需求，本文提出离散原生分辨率视觉Transformer dNaViT：基于冻结预训练编码器，采用轻量残差调制、分组乘积量化设计，兼顾语义与像素信息。其作为通用离散视觉分词器，在17项视觉理解、生成、编辑基准上持平或超越专用基线，验证了紧凑离散词表可作为通用视觉表征，支撑统一多模态范式。

## <a href="https://arxiv.org/abs/2611.12885" target="_blank" rel="noopener noreferrer">World In-Context Learning for Agentic Robot Manipulation</a>

*HF ★ 12 · Heng Fang, Zehui Guo, Yuehan Zhang… · [HF 镜像](https://huggingface.co/papers/2611.12885)*

针对传统机器人操作策略绑定训练分布、现有上下文学习缺当前环境反馈效果差的痛点，研究发现上下文学习习得的是可跨场景迁移的语义信息，据此提出世界上下文学习（WICL）范式，搭建RoboScript架构，仅需单演示加仿真演练存为任务记忆、无需梯度更新，在50项操作任务上成功率超最优训练策略20个百分点，可跨分布、跨实体迁移到真机。

## <a href="https://arxiv.org/abs/2611.14033" target="_blank" rel="noopener noreferrer">Few-Step Streaming Video Generation via Condition Shifting</a>

*HF ★ 9 · Deyuan Liu, Jungang Li, Kaiwen Zheng… · [HF 镜像](https://huggingface.co/papers/2611.14033)*

为降低流视频生成少步采样的训练开销，该文提出条件移位机制改造APEX模型，同套参数可同时实现内容生成与伪样本估算，无需DMD所需的独立伪分数网络。实验显示其指令遵循用户偏好较S2-Avatar高30%，视觉效果更优，同配置下比DMD显存低4.4%、迭代快9.2%，仅运动质量略逊于S2-Avatar。

## <a href="https://arxiv.org/abs/2611.03142" target="_blank" rel="noopener noreferrer">DepthGraft: Structural Regularization through Hierarchical Cross-Layer KV Reconstruction</a>

*HF ★ 6 · Xiaohan Qin, Xiangdong Zhang, Yu Wang… · [HF 镜像](https://huggingface.co/papers/2611.03142)*

针对Pre-LN架构大模型加深时存在层间信息稀释、现有跨层连接方案额外开销高的问题，本文提出DepthGraft分层KV共享架构：以步长对齐的浅中层KV对重构深层KV，既可作为结构正则项优化KV表征，还能降低1/3KV缓存。0.5B-16B稠密与MoE模型实验显示其下游任务普适提效，16B MoE上MMLU-Pro最高提7%，适配大规模预训练。

## <a href="https://arxiv.org/abs/2611.12411" target="_blank" rel="noopener noreferrer">PhysOPSD: Code as Privilege for Physically Plausible Video Generation</a>

*HF ★ 6 · Harold Haodong Chen, Rui Peng, Lingteng Qiu… · [HF 镜像](https://huggingface.co/papers/2611.12411)*

针对现有视频生成模型物理动态合理性弱、传统微调/强化学习优化存在固有缺陷的问题，本文提出PhysOPSD方法，引入可执行代码作为特权物理上下文，通过专属引擎将真实物理场景转换为可验证仿真程序，搭配双层特权机制与可控物理变量设计。实验显示其仅用3千样本，就远超基线物理合理性，还保留通用生成质量，适配多类基座。
