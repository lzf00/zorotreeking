# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2607.28618" target="_blank" rel="noopener noreferrer">AskChem: Claim-Centered Infrastructure for Chemistry Literature Synthesis</a>

*HF ★ 17 · Bing Yan, Gregory Wolfe, Stefano Martiniani… · [HF 镜像](https://huggingface.co/papers/2607.28618)*

现有化学文献检索仅返回排序文档，需人工跨文献整合校验信息。对此研发的AskChem将检索单位从论文改为带DOI来源、证据定位的原子化化学主张，配套分层检索分类体系、证据关联图谱等结构，已索引14.7万篇论文的240万条主张，支持多端访问。测评显示其赋能的大模型阅读器DOI可解析率达100%，引文密度为受试系统最高。

## <a href="https://arxiv.org/abs/2607.27703" target="_blank" rel="noopener noreferrer">SpatialCLI: Learning to Reason With Spatial Tools, Then Without Them</a>

*HF ★ 14 · Yang Zhou, Zixuan Huang, Sunzhu Li… · [HF 镜像](https://huggingface.co/papers/2607.27703)*

针对通用视觉语言模型空间感知不足、专业视觉模型无法输出任务决策的能力错配问题，本文提出三阶段SpatialCLI框架：调用空间工具补全感知、用冷启动监督微调+智能体强化学习优化工具使用、基于成功轨迹内化专业感知能力，还发布了含516个样例的感知基准。测试显示其带工具时将Qwen3-VL性能从29.3%提至84.6%，超同类带工具方案72.1%的成绩，内化后无工具仍保持73.8%性能。

<FeedbackButtons slug="item:arxiv-2607.27703" client:visible />

## <a href="https://arxiv.org/abs/2607.28624" target="_blank" rel="noopener noreferrer">PhiZero: A World Model Built Around Physical Language</a>

*HF ★ 8 · Shuyao Shang, Yuqi Wang, Ruopeng Gao… · [HF 镜像](https://huggingface.co/papers/2607.28624)*

本文提出基于物理语言的物理世界模型PhiZero。针对现有模型直接在像素空间预测视频、动力学规律隐式嵌入高维网络的缺陷，该模型自监督从真实场景视频学习离散物理语言表示，采用先推理后渲染范式，先推导世界演化的物理语言序列再生成对应视频。实验验证其物理一致性优异，可支撑交互建模、细粒度动作仿真、零样本动作迁移等任务。

## <a href="https://arxiv.org/abs/2607.28272" target="_blank" rel="noopener noreferrer">MemHarness: Memory Is Reconstructed, Not Replayed</a>

*HF ★ 6 · Rong Wu, Daocheng Fu, Licheng Wen… · [HF 镜像](https://huggingface.co/papers/2607.28272)*

现有记忆增强大模型多直接回放检索到的静态历史经验，易因和当前决策场景不匹配出现负迁移。受人类记忆主动重构机制启发，本文提出MemHarness框架，经GRPO端到端训练的统一策略模型会结合当前状态重构经验输出决策指导。实验显示其性能显著优于纯RL、静态记忆基线，分布外鲁棒性强，还可提升模型内在推理能力。

## <a href="https://arxiv.org/abs/2607.26760" target="_blank" rel="noopener noreferrer">Metis: Memory Foundation Model</a>

*HF ★ 6 · Zeyu Zhang, Ziliang Guo, Yihang Sun… · [HF 镜像](https://huggingface.co/papers/2607.26760)*

针对当前AI智能体记忆依赖外部模块、原生记忆能力研究不足的问题，该研究提出记忆基础模型范式，推出首个原型Metis。其内置持久动态记忆状态，通过记忆注意力调取信息，无需梯度、仅前向传播即可完成记忆更新，实验验证其具备原生记忆能力，配套项目与模型检查点已开源。
