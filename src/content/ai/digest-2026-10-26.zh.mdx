# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2610.30932" target="_blank" rel="noopener noreferrer">UserArena: Benchmarking Interactive User Simulation for Long-Horizon Shopping Agents</a>

*HF ★ 19 · Jujia Zhao, Jiakai Tang, Jing Yu… · [HF 镜像](https://huggingface.co/papers/2610.30932)*

针对电商长周期智能推荐代理缺乏真实交互评测基准、难对齐线上A/B结果的痛点，本文提出UserArena交互基准，覆盖1.1万用户的6.47万条真实会话轨迹，含56万余商品、13类交互动作，支持五级全链路离线评测。同时提出同策略轨迹蒸馏方法OPTD，依托轨迹级意图提升长交互模拟保真度，实验显示其在该基准下表现最优，最贴近线上策略实际效果。

## <a href="https://arxiv.org/abs/2610.32253" target="_blank" rel="noopener noreferrer">RSIHub: A Composable Framework for Agent-Evolution Methods</a>

*HF ★ 17 · Zimu Wang, Xiaobo Wang, Siyu Ye… · [HF 镜像](https://huggingface.co/papers/2610.32253)*

针对智能体进化方法重复开发实验底座的痛点，本文提出可组合开源框架RSIHub：采用可复用算子+可变资源声明的配方机制，内置执行、评测、溯源等通用能力，研究者无需修改核心即可适配各类进化策略。评测显示，框架下的进化方法最高将pass@1提升13.5个百分点，但方法排名随场景变化，优化收益不总能跨任务迁移。

## <a href="https://arxiv.org/abs/2610.32965" target="_blank" rel="noopener noreferrer">RynnUnify: Towards Unified Embodied Brain</a>

*HF ★ 8 · Minghao Zhu, Bohan Hou, Kun Xiang… · [HF 镜像](https://huggingface.co/papers/2610.32965)*

本文提出160亿参数的统一具身模型RynnUnify，依托交错式视频-语言推理，兼具具身理解与长时序视觉规划能力，配套研发强化学习智能体扩展、适配机器人控制的世界动作扩展及专属评测基准。实验显示其多项具身任务表现显著优于现有基线，可作为具身智能通用基础底座，向统一具身脑目标迈进一步。

## <a href="https://arxiv.org/abs/2610.27103" target="_blank" rel="noopener noreferrer">Omni-Woodpecker: Hallucination Correction via Evidence-Prior Rebalancing for Omni LLMs</a>

*HF ★ 7 · Zijian Liu, Chaoyou Fu, Yan Yang… · [HF 镜像](https://huggingface.co/papers/2610.27103)*

针对全模态大模型音视频推理的跨模态幻觉问题，现有仅在输出层干预的方案未解决融合表征中事实证据与训练先验的纠缠缺陷，本文提出免训练框架Omni-Woodpecker：先识别跨模态冲突，正交拆分表征后解码前重平衡证据与先验权重抑制幻觉。该框架跨架构泛化性强，在多款主流模型及多个基准上均实现稳定性能提升，代码已开源。

## <a href="https://arxiv.org/abs/2610.31569" target="_blank" rel="noopener noreferrer">Echo: Coupled Action and Task Status Signal Denoising for Vision Language Action Models</a>

*HF ★ 2 · Yufeng Liu, Bohao Fan, Juntu Zhao… · [HF 镜像](https://huggingface.co/papers/2610.31569)*

针对现有视觉语言动作（VLA）模型新增任务状态预测需细粒度标注、额外配套模块，且未充分挖掘状态信号对动作生成的引导价值的痛点，本文提出Echo框架：无需帧级进度标注，将停止、失败两类状态信号作为动作维度联合去噪，构造三类轨迹实现弱监督，让状态信号更快去噪以引导动作生成。实机实验显示其状态预测精准，策略性能稳定提升。
