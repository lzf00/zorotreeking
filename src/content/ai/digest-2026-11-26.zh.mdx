# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2611.32351" target="_blank" rel="noopener noreferrer">LookAnything: A Foundation Model for Holistic Gaze Following</a>

*HF ★ 0 · Jiayu Tang, Yuchen Zhou, Hongsheng Wu… · [HF 镜像](https://huggingface.co/papers/2611.32351)*

针对现有视线跟随方法依赖头姿、深度等辅助输入、泛化性差、输出形式单一的问题，本文提出通用基础模型LookAnything，核心引入可学习视线先验查询，无需辅助输入，基于自建多任务基准HoliGaze跨域训练，支持多形式输出与多类视线任务。实验显示其性能优于33个主流视觉语言模型，比肩专用检测模型，跨域泛化与现实部署表现优异。

## <a href="https://arxiv.org/abs/2611.30564" target="_blank" rel="noopener noreferrer">Seeing Is Locating: Spatial Awareness and Geographic Bias in Decision Language Models</a>

*HF ★ 1 · Wilson Wongso, Hada Melino Muhammad, Xiachong Lin… · [HF 镜像](https://huggingface.co/papers/2611.30564)*

针对输出标签分布的决策大模型空间感知能力、地理偏差尚不明确的问题，该研究构建了含地理感知图像分类、地点多主题评分两类任务的多模态评测基准GeoDecisions。评测发现模型空间感知需依赖视觉输入，仅文本坐标信息不足，且存在显著地理偏差，对低社会经济水平地区评分更低。研究还提出免训练优化方案，可提升空间感知且不明显加剧偏差。

<FeedbackButtons slug="item:arxiv-2611.30564" client:visible />

## <a href="https://arxiv.org/abs/2611.32393" target="_blank" rel="noopener noreferrer">Fractal Neural Synthesis: Constant-Storage Procedural Weight Derivation via Complex Quadratic Boundary Dynamics</a>

*HF ★ 1 · Volkan Dagli, Zerrin Dagli, Daghan Dagli · [HF 镜像](https://huggingface.co/papers/2611.32393)*

针对传统神经网络参数量大、闪存占用随参数线性增长，难以适配边缘微控制器的痛点，该研究提出分形神经合成架构：仅用24字节锚定在复数二次分岔边界的种子即可程序化生成隐层权重，配套专属采样设计并证明熵界。实测较INT8线性基线精度高3.6~10.8个百分点，闪存占用较Float32 MLP最高降129倍。

<FeedbackButtons slug="item:arxiv-2611.32393" client:visible />

## <a href="https://arxiv.org/abs/2611.25946" target="_blank" rel="noopener noreferrer">Point Dynamics as Proxy for Robotic World Models</a>

*HF ★ 1 · Dong An, Tianyu Liu, Haoran Ding… · [HF 镜像](https://huggingface.co/papers/2611.25946)*

针对现有机器人世界模型交互后物体运动易失真的问题，该研究拆分动力学预测与视觉渲染环节，引入3D点动力学作为中间代理：将首帧转为3D点，经习得的点动力学模型模拟动作响应后渲染为视频。实验显示该方法可在不降低画质的前提下，将数据集及真实双臂机器人场景的物体运动误差降6%以上，动力学建模优化可有效提升世界模型保真度。

<FeedbackButtons slug="item:arxiv-2611.25946" client:visible />

## <a href="https://arxiv.org/abs/2611.27404" target="_blank" rel="noopener noreferrer">Degradation of Language Models under Controlled Load: Synchronization, Rule Execution and Misfires on the Background</a>

*HF ★ 0 · Hennadii Kutomanov · [HF 镜像](https://huggingface.co/papers/2611.27404)*

针对大模型负载升高时性能退化成因不明的问题，该研究将退化拆分为同步偏差、规则执行错误、随机误改三类，控制文本长度、规则数量等五类变量开展替换测试，结合输出对齐与统计模型拟合退化的负载依赖规律，生成模型“性能护照”，已完成7款模型的护照构建，为神经网络细粒度行为研究提供新路径。
