# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2609.04304" target="_blank" rel="noopener noreferrer">Iris: Climbing to the Search Frontier</a>

*HF ★ 8 · Ziyuan Liu, Hengqi Liu, Zichuan Wang… · [HF Mirror](https://huggingface.co/papers/2609.04304)*

This paper introduces two search agents of different parameter scales, Iris-mini and Iris-pro. The team constructed a multi-hop hard search dataset without string matching clues by reverse-engineering web links, adopted an alternating iterative SFT-RL training paradigm, and conducted evaluations with strictly controlled variables. Both models achieved the best performance among open-source search agents of the same parameter scale on four search benchmarks. The model weights and full-process implementation will be open-sourced later.

## <a href="https://arxiv.org/abs/2609.04523" target="_blank" rel="noopener noreferrer">MaxKernel: Agentic Kernel Generation for TPUs</a>

*HF ★ 3 · Shangkun Wang, Nina Cai, Charles Hoong… · [HF Mirror](https://huggingface.co/papers/2609.04523)*

To address the pain point that developing high-performance custom kernels for TPUs requires deep hardware expertise and has a high entry barrier, this research proposes MaxKernel, a multi-agent kernel generation system that supports three modes: human-in-the-loop collaborative design, fully automatic metric-driven optimization, and graph-based global design space exploration. Shared sub-agents complete the entire development workflow. Tested against the JaxBench benchmark and real model workloads, the performance of the generated kernels matches that of expert manually tuned results, and the system is now open source.

<FeedbackButtons slug="item:arxiv-2609.04523" client:visible />

## <a href="https://arxiv.org/abs/2609.05258" target="_blank" rel="noopener noreferrer">Ask Before You Optimize: Dynamic Pre-Formulation Clarification for Interactive Optimization</a>

*HF ★ 2 · Sihan Ge, Yichen Lin, Chenyu Zhou… · [HF Mirror](https://huggingface.co/papers/2609.05258)*

To solve the problem that when large models generate operations research optimization models from natural language, modeling deviations often occur due to incomplete user requirements, this research launches the OR-Clarify benchmark, which can quantitatively evaluate the clarification ability of agents before modeling. It also proposes a two-stage framework InterOPT, which can identify key information gaps and independently decide whether to ask questions or terminate the interaction. Experiments show that its performance far exceeds baselines in multiple-choice scenarios, and is on par with existing state-of-the-art solutions in open-ended scenarios.

## <a href="https://arxiv.org/abs/2609.05416" target="_blank" rel="noopener noreferrer">WorldSculpt: Generating Compositional Worlds from Grounded Videos</a>

*HF ★ 2 · Muyao Niu, Jixuan He, Ruihan Yu… · [HF Mirror](https://huggingface.co/papers/2609.05416)*

To address the challenge of 3D compositional generation for highly occluded, dense and cluttered scenes, this paper proposes the WorldSculpt method: it extends the multi-view conditional pathway based on the single-object 3D generation model Pixal3D, and only requires single-object fine-tuning to generalize to complex scenes without scene-level training. The team also built UE-MeshyScene, a dense scene benchmark with precise annotations. Experiments show that this method outperforms existing solutions, with more significant advantages in more complex scenes. It can also convert 3DGS scenes into compositional mesh scenes to meet the needs of AR/VR and other applications.

<FeedbackButtons slug="item:arxiv-2609.05416" client:visible />

## <a href="https://arxiv.org/abs/2609.04061" target="_blank" rel="noopener noreferrer">When Models Edit Too Much: On the Fidelity of Minimal Code Edits</a>

*HF ★ 2 · Tongyao Zhu, Wei Hern Lim, Min-Yen Kan · [HF Mirror](https://huggingface.co/papers/2609.04061)*

This research targets the over-editing problem of large models during code repair, built a test set containing 400 known minimal patches for testing, and found that even powerful models like GPT-5.5 often output redundant modifications. Adding instructions to retain the original implementation can significantly reduce the degree of over-editing and slightly improve the repair pass rate. Reinforcement learning is more suitable for cross-scenario faithful editing needs than supervised fine-tuning, and editing fidelity should be regarded as an independent quality dimension for code repair.

*Hugging Face*

This research addresses the pain points of small models being prone to format errors and content deviations in structured outputs. ## <a href="https://lilianweng.github.io/posts/2026-07-04-harness/" target="_blank" rel="noopener noreferrer">Harness Engineering for Self-Improvement</a>

*Lilian Weng*

This article sorts out the conceptual evolution of Recursive Self-Improvement (RSI): In 1965, Good first proposed the relevant concept, defining a "superintelligent machine" that can surpass all human intellectual activities and design better machines on its own. In 2008, Yudkowsky clarified that the core of RSI is the feedback loop where AI uses its existing intelligence to optimize its own cognitive mechanism. Current RSI in the AI field includes both the model directly rewriting its own weights, and broadly covers the optimization of training pipelines.

*QbitAI*

The Recurrent Transformer technology adopted by GPT-6 Astra (where the same set of Transformer layers runs repeatedly, trading computational depth for parameter scale) has sparked security controversy.
