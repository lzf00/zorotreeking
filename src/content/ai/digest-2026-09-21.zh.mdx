# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2609.22000" target="_blank" rel="noopener noreferrer">RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents</a>

*HF ★ 25 · Shuai Bai, Jiayong Deng, Yikun Fu… · [HF 镜像](https://huggingface.co/papers/2609.22000)*

针对当前计算机操作智能体割裂GUI交互与代码开发、无法适配真实混合工作流的缺陷，本文提出跨5类系统的可复现可验证测试框架RecreationWorld，配套覆盖多领域的250项任务基准RecreationBench。实测显示当前最优的GPT-6 Astra整体通过率仅58.1%，全测试用例通过率仅2.8%，现有智能体交互、计算输出复刻能力远弱于静态界面复刻，仍有极大提升空间。

## <a href="https://arxiv.org/abs/2609.22068" target="_blank" rel="noopener noreferrer">CodeMidas: Scaling Agentic Coding RL Environments from Code Itself</a>

*HF ★ 21 · Bowen Ye, Lei Li, Shicheng Li… · [HF 镜像](https://huggingface.co/papers/2609.22068)*

针对现有编码智能体强化学习训练任务依赖开发工单、提交记录等工件、覆盖范围有限的问题，该研究提出CodeMidas自动化流水线，仅以源码为输入，可从开源代码库自动提取功能、构建验证测试、筛选得到训练任务，构建了覆盖23种语言、15个领域的5545个任务数据集。用该数据集训练的智能体在5项基准最高提分17%，证实源码可作为编码RL训练环境的高可扩展来源。

<FeedbackButtons slug="item:arxiv-2609.22068" client:visible />

## <a href="https://arxiv.org/abs/2609.15779" target="_blank" rel="noopener noreferrer">EvoOntology: A Self-Evolving Ontology Layer for Data Agents</a>

*HF ★ 15 · Meiduo Chong, Shaolei Zhang, Ju Fan… · [HF 镜像](https://huggingface.co/papers/2609.15779)*

针对数据智能体处理异构数据时存在的智能体-数据鸿沟，现有直接探源、人工语义层方案难以适配大规模场景的问题，本文提出EvoOntology自演进本体层：封装为含三类层级的MCP服务，搭配自主构建智能体和带校验的归因引导自演化机制。多基准、多基座大模型实验显示其性能显著优于现有方案，可有效弥合鸿沟。

<FeedbackButtons slug="item:arxiv-2609.15779" client:visible />

## <a href="https://arxiv.org/abs/2609.05571" target="_blank" rel="noopener noreferrer">Grounded Skill Synthesis from Code at Scale for Agentic Intelligence</a>

*HF ★ 8 · Yongqi Tong, Pan Wang, Hang Wang… · [HF 镜像](https://huggingface.co/papers/2609.05571)*

针对智能体现有技能获取存在依赖特定环境交互、缺乏可执行验证的痛点，研究提出全自动流水线Code2Skill，可从开源代码提炼可落地、可验证的智能体技能。其基于近2万GitHub库构建的百万级技能库，可使模型平均性能提升11.7%，效果优于轨迹类技能库，AI生成代码提炼的技能通过率与人类代码基本持平。

<FeedbackButtons slug="item:arxiv-2609.05571" client:visible />

## <a href="https://arxiv.org/abs/2609.21749" target="_blank" rel="noopener noreferrer">GraphSkillEvo: Evolutionary Optimization of Graph-Structured Agent Skills</a>

*HF ★ 3 · Rui Sun, Zhi Zheng, Zhenkun Wang… · [HF 镜像](https://huggingface.co/papers/2609.21749)*

针对大语言模型智能体现有非结构化技能优化缺乏明确工作流引导、无约束自然语言搜索空间大优化效率低的痛点，该研究将技能建模为图结构（节点对应执行步骤、边对应上下文跳转），提出种群式进化优化框架GraphSkillEvo，通过变异、交叉算子实现比纯大模型自迭代更全面的技能空间探索。5类基准测试显示其一致优于基线SkillOpt，精度最高提升4.01%。
