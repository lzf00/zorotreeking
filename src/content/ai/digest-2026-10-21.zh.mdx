# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2610.26203" target="_blank" rel="noopener noreferrer">Focused Omni-Modal GUI Agents</a>

*HF ★ 36 · Fuyao Zhang, Wenwen He, Jiaming Zhang… · [HF 镜像](https://huggingface.co/papers/2610.26203)*

针对全模态GUI智能体统一处理全量上下文易引发序列分心、轨迹漂移的问题，本文提出轻量适配器FocusGUI：可按单步决策需求动态排序多模态通道优先级，压缩相关特征注入冻结解码器，仅靠动作监督训练无需微调主干。实验显示其相较冻结主干平均类型匹配提33.2、精确匹配提3倍，较现有最优增强方法类型匹配高30.1。

## <a href="https://arxiv.org/abs/2610.28578" target="_blank" rel="noopener noreferrer">Sage-A1.5: From Long-Horizon Execution to Scientific Exploration with Capability Composition</a>

*HF ★ 31 · Wenjie Lou, Tianshuo Peng, Shiyang Feng… · [HF 镜像](https://huggingface.co/papers/2610.28578)*

Sage-A1.5是基于前代A1开发的35B参数混合专家架构智能体模型，核心做了三点优化：支持多子代理上下文隔离的并行任务编排、带进度校验和策略反思的验证机制、可开展开放式探索研究的科研能力。相较前代可更可靠高效完成长周期复杂任务，还能支撑跨学科科研探索，为学界相关研究提供了可用基础。

## <a href="https://arxiv.org/abs/2610.28630" target="_blank" rel="noopener noreferrer">SolarRenderer: Few-Step Generative Reference Rendering</a>

*HF ★ 22 · Guian Fang, Shengju Qian, Dongyue Lu… · [HF 镜像](https://huggingface.co/papers/2610.28630)*

针对现有视频渲染器引擎绑定、采样步数多、泛化性弱的痛点，本文提出SolarRenderer结构条件渲染器，通过两个轻量LoRA适配冻结大模型骨干，仅需4步采样，速度为50步方案的12.3倍，块因果变种可实时生成768p视频。基于13.6万对齐片段训练后，效果达SOTA，可泛化到骨架、手绘图等11种未见结构表示。

<FeedbackButtons slug="item:arxiv-2610.28630" client:visible />

## <a href="https://arxiv.org/abs/2610.25844" target="_blank" rel="noopener noreferrer">SWIFT: Self-guided Weak-to-strong dIFfusion models via Target extrapolation</a>

*HF ★ 18 · Yanjin He, Cuifeng Shen, Wanzhou Lei… · [HF 镜像](https://huggingface.co/papers/2610.25844)*

针对扩散模型训练成本高、推理引导额外开销大的痛点，本文提出SWIFT自引导弱到强扩散训练方法：复用冻住的早期训练弱去噪器外推回归目标，强化模型欠拟合分量，训练后丢弃引导无额外推理开销。理论证明该方法可降低误差，实验中ImageNet-256任务仅用半算力超基线FID，无推理引导也能实现高质量生成。

<FeedbackButtons slug="item:arxiv-2610.25844" client:visible />

## <a href="https://arxiv.org/abs/2610.26067" target="_blank" rel="noopener noreferrer">PhysSkin++: Real-Time and Generalizable Physics-Based Animation via Self-Supervised Neural Skinning</a>

*HF ★ 12 · Yuanhang Lei, Baofei Liu, Xingxuan Li… · [HF 镜像](https://huggingface.co/papers/2610.26067)*

针对跨多样3D形体、离散表示的实时物理动画泛化难题，该文提出PhysSkin++物理感知框架：采用神经蒙皮场自编码器，无需逐对象训练即可生成形变子空间，搭配结合梯度校正的物理自监督策略稳定约束优化，新增自监督互补目标学习弹性响应。经验证其支持多类3D表示的实时可控带碰撞动画，跨形状泛化性优异。
