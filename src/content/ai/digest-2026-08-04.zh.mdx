## <a href="https://arxiv.org/abs/2607.28590" target="_blank" rel="noopener noreferrer">VAD: Attributing Visual Evidence for Target Reconstruction in Multimodal On-Policy Distillation</a>

*HF ★ 2 · Kangning Zhang, Yixing Li, Shuai Shao… · [HF 镜像](https://huggingface.co/papers/2607.28590)*

针对多模态同策略蒸馏监督信号混杂、无法区分视觉支撑修正的问题，本文提出视觉归因蒸馏（VAD）方法，通过反事实推断分离教师修正中由视觉证据支撑的部分，重构监督目标作为主训练信号，仅保留弱教师正则。4B、9B参数量级下6个细粒度视觉基准测试中，VAD显著优于现有蒸馏方案，错误修正精准度更高。

## <a href="https://arxiv.org/abs/2608.01755" target="_blank" rel="noopener noreferrer">Deferred Exposure of Future Trajectories for Verifiable Reasoning in Autonomous Driving VLMs</a>

*HF ★ 0 · Zixuan Huang, Yang Zhou, Kaixuan Wang… · [HF 镜像](https://huggingface.co/papers/2608.01755)*

# arXiv cs.LG

## <a href="https://arxiv.org/abs/2607.28633" target="_blank" rel="noopener noreferrer">Topology-Aware Data Movement for Disaggregated GPU Inference</a>

*Sanjeev Rao Ganjihal*

针对LLM解耦推理（预填充、解码分属不同GPU池）场景下，现有KV缓存传输采用统一RDMA、忽略GPU互联拓扑带宽差异导致性能不足的问题，本文设计拓扑感知传输编排器，结合分层流水线传算重叠、MoE模型NVLink域感知调度、CXL3.0内存扩展溢出三层机制，经理论测算相较统一RDMA可降低3-18倍传输延迟。

## <a href="https://arxiv.org/abs/2607.28665" target="_blank" rel="noopener noreferrer">Sensitivity Analysis of GRU, LSTM and Transformer Encoder in Classification of Automated Driving Systems</a>

*Bidhya Shrestha, Christos Papadopoulos*

本研究面向自动驾驶系统识别的安全、监管需求，采用GRU、LSTM、Transformer编码器三种时序分类模型，基于车载网联数据区分三类L2级自动驾驶系统与人工驾驶。干净数据下三类模型F1均超0.9，Transformer表现最优；鲁棒性测试显示事件类扰动影响极小，时间抖动会让三类模型F1骤降至0.44-0.5区间。

## <a href="https://arxiv.org/abs/2607.28667" target="_blank" rel="noopener noreferrer">Guarantees on Dynamical System Distinguishability for LLM Token Generation</a>

*Mohamed Akrout, Dan Wilson*

本文针对基于动态系统（DS）的LLM判别方法缺乏理论支撑的问题，将分类任务形式化为两个随机线性DS的二元假设检验。研究证明：忽略token动态的分类器存在固有精度下限；DS方法错分率随序列长度指数衰减，衰减速率由两个DS的谱距决定；同时给出跨嵌入模型泛化的可迁移判别性下界，为该类方法的实证效果提供了理论依据。
