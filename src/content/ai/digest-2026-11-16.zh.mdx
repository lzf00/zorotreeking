# Hugging Face Daily Papers

## <a href="https://arxiv.org/abs/2611.18359" target="_blank" rel="noopener noreferrer">Envisioning Agentic Robotics: A New Era of Robotic Systems</a>

*HF ★ 28 · Grid Robotics, Qingfeng Lan, Duo Li… · [HF 镜像](https://huggingface.co/papers/2611.18359)*

本文指出GPT-6 Astra催生智能体机器人新范式，无需为每类任务单独训练策略，可依托基座模型实现开放世界具身任务的闭环决策。针对领域暂无统一定义、评估体系与研究路线的现状，作者提出以基座模型加具身套件组成的「具身系统2」为决策核心，配套双维度评估框架，明确了物理自主落地的核心挑战与渐进式研究路线。

## <a href="https://arxiv.org/abs/2611.18397" target="_blank" rel="noopener noreferrer">Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent</a>

*HF ★ 18 · Run Luo, Kuan Zhang, Qi Deng… · [HF 镜像](https://huggingface.co/papers/2611.18397)*

本文提出面向长时程实时游戏任务的通用视-语-行动基础模型Gamer。其采用端到端架构整合感知、记忆与推理模块，基于数万小时键鼠交互轨迹预训练，经稀疏思维指令调优、多轮强化学习训练策略，搭配云边推理引擎控制延迟。该模型在2D、3D游戏基准上性能媲美资深玩家，为跨数字、物理世界的通用智能体研发提供新思路。

<FeedbackButtons slug="item:arxiv-2611.18397" />

## <a href="https://arxiv.org/abs/2611.07226" target="_blank" rel="noopener noreferrer">Loopback Transformer: Towards a Unified View of Residual Looped Transformers</a>

*HF ★ 10 · Xuan Ouyang, Zefan Cai, Chenlong Zhang… · [HF 镜像](https://huggingface.co/papers/2611.07226)*

本文针对循环Transformer仅靠参数共享无法明确计算结果复用规则的问题，从残差连接的深度存储视角优化，提出Loopback Transformer：单独保留输入通路，以几何衰减设置总更新权重、注意力动态分配权重。同等训练成本下，其参数量仅为基线的40%-75%时验证损失更低，13项下游任务平均准确率优于标准Transformer及7种同类循环结构。

<FeedbackButtons slug="item:arxiv-2611.07226" />

## <a href="https://arxiv.org/abs/2611.14504" target="_blank" rel="noopener noreferrer">Emergent Biological Capabilities in a Foundation Model for Molecular Interactions</a>

*HF ★ 8 · Adi Mashiach · [HF 镜像](https://huggingface.co/papers/2611.14504)*

研究团队研发分子互作基础模型Bonbon，仅用3.2万亿对蛋白-配体序列训练，无需结构数据或任务特定标注，便涌现出三类跨层级零样本分子互作识别能力，泛化性优异。能力随参数量突变涌现，无法通过预训练损失预判，湿实验验证新化合物抑靶命中率达61.5%，性能领先且推理速度远超传统共折叠方法。

<FeedbackButtons slug="item:arxiv-2611.14504" />

## <a href="https://arxiv.org/abs/2611.18338" target="_blank" rel="noopener noreferrer">MEM-SQL: Memory-Empowered Text-to-SQL</a>

*HF ★ 6 · Xiaoqi Wang, Wenqi Pei, Shizheng Hou… · [HF 镜像](https://huggingface.co/papers/2611.18338)*

针对现有Text-to-SQL基准忽略同库历史查询可复用性的问题，研究者构建了含1600条请求的HARE基准，评测历史SQL复用的准确率与开销。提出分层存储可复用SQL资源、搭配按需Schema链接的MEM-SQL方法，在HARE上准确率较无历史直接生成提升12.9个百分点，输入token减76.6%、延迟降68.8%，按需链接机制可通用降低同类内存架构的生成成本。

<FeedbackButtons slug="item:arxiv-2611.18338" />

*Henry Bell, Caroline Zhang, Dhaval Potdar…*

## <a href="https://arxiv.org/abs/2611.17412" target="_blank" rel="noopener noreferrer">WETW: Learning Pair-Specific Weighted Euclidean Distances for Efficient DTW Search</a>

*Christos Panourgias, Qitong Wang, George Tzagkarakis…*

针对动态时间规整（DTW）时序相似搜索效率低、现有学习式度量采用固定规则不匹配DTW逐对对齐特性的问题，本文提出WETW自适应度量，用对称网络预测逐对嵌入权重，搭配保时序信息的WESEE编码器与排序正则，配套过滤-校验管线WETW-FV。实测比现有最快精确DTW搜索方法快11.4倍，长时序下提速达40倍，同速度下召回率远优基线。

*Salma Tarmoun, Lachlan Ewen MacDonald, Konstantinos Emmanouilidis…*
