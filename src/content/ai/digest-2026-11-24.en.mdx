## <a href="https://arxiv.org/abs/2611.28202" target="_blank" rel="noopener noreferrer">AutoPILOT: A Visual Agent Harness for Real-Time Gameplay</a>

*HF ★ 13 · Mark Zhao, Pengcheng Wang, Rui Yang… · [HF Mirror](https://huggingface.co/papers/2611.28202)*

To address the poor performance of multimodal LLMs in real-time gameplay, the research identified that the core bottleneck lies in the action output link of the agent framework. The proposed AutoPILOT framework supports outputting basic actions, open-loop macros, or closed-loop controllers requiring no subsequent calls with a single model invocation, and also built the AFK-Bench real-time game test set. At the same cost, its real-time success rate is 30 percentage points higher than the baseline VISTA, with API cost only 1/5 of the latter, verifying the core research value of the action conversion module.

## <a href="https://arxiv.org/abs/2611.29338" target="_blank" rel="noopener noreferrer">A Glimpse of Training VLMs as Foundation Models for Robotic Manipulation</a>

*HF ★ 10 · Meng-Hao Guo, Yi Zhang, Zhe-Han Mo… · [HF Mirror](https://huggingface.co/papers/2611.29338)*

To address the issue that training details of GPT-6 Astra's strong generalizable robot control capabilities are undisclosed and hard to reproduce, the research proposed the nanoAstra training scheme, combining semantic action modeling and capability-preserving supervised fine-tuning techniques, trained on over 5000 hours of robot data plus general VQA data. Its zero-shot success rate on the RoboTwin2.0 benchmark reaches 17.8%, far exceeding similar baselines, and it has fast inference speed, reducing robot idle rate from 35.0% to 6.9%.

## <a href="https://arxiv.org/abs/2611.28833" target="_blank" rel="noopener noreferrer">Self-WSP: Can Language Models Improve Themselves Through Weight-Space Programming?</a>

*HF ★ 7 · Guoming Ling, Shanshan Zhong, Kaixuan Zhang… · [HF Mirror](https://huggingface.co/papers/2611.28833)*

This paper proposes the Self-WSP self-optimization framework, which allows the Qwen3.5-0.8B model to read its own weights, edit and optimize them independently, and act as both problem solver and weight editor during iterations. Experiments show it can greatly improve mathematical reasoning accuracy, modifying as few as 16 parameters at minimum and supporting continuous iterative optimization, but the improvement has poor interpretability: the model does not understand the editing logic, and its performance is comparable to random search-driven WSP. It currently only has recursive self-optimization potential and requires further in-depth research.

<FeedbackButtons lang="en" slug="item:arxiv-2611.28833" client:visible />

## <a href="https://arxiv.org/abs/2611.25476" target="_blank" rel="noopener noreferrer">WeightCode: Installing New Capabilities into Neural Networks via Weight-Space Programming</a>

*HF ★ 6 · Bo Li, Taoyong Cui, Bob Zhang… · [HF Mirror](https://huggingface.co/papers/2611.25476)*

To address the pain point that expanding neural network capabilities requires retraining and makes it difficult to retain original capabilities, this paper proposes the WeightCode weight-space programming framework: it calls a frozen LLM to generate executable weight modification programs, and can implant new capabilities into trained models without gradient training, with implanted capabilities independent of the LLM after installation. Experiments show it outperforms fine-tuning schemes under the same conditions in instruction generalization and image classification robustness, with stackable capabilities and reusable programs, providing a new path for model capability expansion.

# arXiv cs.LG

## <a href="https://arxiv.org/abs/2611.26671" target="_blank" rel="noopener noreferrer">On the loss landscape of the linear neural network: beyond critical points</a>

*Antoine Lejay (PASTA, IECL), Lionel Lenotre (Université de Haute-Alsace)…*

To address the issue that existing research on the loss landscape of linear neural networks mostly focuses on critical points and lacks mesoscopic global characterization, this paper proposes the "critical thalweg" intermediate structure covering all critical points. It not only re-proves relevant classic conclusions from a geometric perspective with looser assumptions, but also enables 2D visualization of the loss landscape. Empirical results show that gradient descent will be attracted by this structure and descend along it to the global minimum of loss.

<FeedbackButtons lang="en" slug="item:arxiv-2611.26671" client:visible />

## <a href="https://arxiv.org/abs/2611.26711" target="_blank" rel="noopener noreferrer">Parasite Features: Causal Abstraction Through Spurious Pathways</a>

*Denis Sutter, Qing Yao, Sasha Boguraev…*

This paper focuses on causal abstraction, the core framework for neural network mechanism interpretability, and discovers a class of "parasite features" that can pass equivalence tests of causal abstraction via spurious pathways, misleading methods such as distributed alignment search to misjudge features actually used by the model. Experiments verify that in syntactic agreement and two-digit addition tasks, distributed alignment search using linear alignment mappings does detect such parasite features, providing a key warning for reliability verification of interpretability methods.

<FeedbackButtons lang="en" slug="item:arxiv-2611.26711" client:visible />

## <a href="https://arxiv.org/abs/2611.26731" target="_blank" rel="noopener noreferrer">Cross-Attack Robust Aggregation for Federated Learning</a>

*Eyhab Al-Masri*

Federated learning faces poisoning risks from malicious clients. Existing aggregation methods either have weak attack resistance, or suffer large accuracy loss under non-IID data and struggle to defend against covert attacks. This paper proposes the FedTether aggregation method, where the server reweights updates based on the deviation of client updates from the coordinate-wise median via robust dead-zone scoring. Experiments show that in scenarios with up to 40% Byzantine nodes, multiple attacks, and partial participation, its accuracy is up to 42 percentage points higher than baselines, with no additional accuracy loss and no need for shared data or validation sets.

# Lil'Log

## <a href="https://lilianweng.github.io/posts/2026-07-04-harness/" target="_blank" rel="noopener noreferrer">Harness Engineering for Self-Improvement</a>

*Lilian Weng*

This paper sorts out the evolution of the concept of Recursive Self-Improvement (RSI): I.J. Good first proposed the relevant concept in 1965, defining a system that can surpass all human intellectual activities and independently design better machines for iteration as an ultra-intelligent machine; in 2008, Eliezer Yudkowsky clarified that the core of RSI is the feedback loop where AI optimizes its own cognitive mechanism based on existing intelligence. Current RSI in the AI field can be divided into two categories: directly rewriting its own weights, and optimizing training pipelines.
